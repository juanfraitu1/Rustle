Copy assignment · O2

How a read is assigned to a copy

A read that fits several copies (MAPQ 0) is assigned by evidence, not similarity. Reveal its bases one PSV at a time: every position that matches only one copy is copy-specific evidence, and the chance it arose by sequencing error, p ≈ εᵏ, plunges. Assign when p < α/(K−1); otherwise the read stays tied. The last two reads are traps — a sequencing error and a chimeric copy→copy read — showing what the test rejects. Pick a read and press play.

Notation · what each symbol means

readone transcript molecule (a full-length HiFi / Iso-Seq read)
copyone paralog — a near-identical gene duplicate in the family
PSVa position where the copies differ (the columns above)
Knumber of candidate copies in the family — here K = 3
kcopy-specific matches the read makes to its best copy — the evidence it has accumulated
ε (eps)per-position error probability, from the read's own base quality: ε = 10^(−Q/10) — ≈10⁻³ at HiFi Q30, ≤10⁻⁴ at Q40, capped at 0.25 for a low-Q base (so it barely counts); 10⁻⁴ for a junction
α (alpha)the significance level = target per-read false-assignment rate = 10⁻³. A calibrated rate, not an identity cutoff.
α/(K−1)the Bonferroni threshold — corrects for testing the read against the K−1 rival copies
pthe certificate: P(this much copy-specific match is sequencing error) ≈ εᵏ  (exactly, a Poisson-binomial upper tail)
H₀the null hypothesis: the read actually came from a competitor copy
ruleassign iff p < α/(K−1); otherwise certify tied — never split 1/k
artifactsa sequencing error is outvoted (and a lone error never makes a PSV); a chimeric / read-through read matches two copies → abstained & flagged recombinant
The real-vs-error significance test is adapted from IsoCon (Sahlin, Tomaszkiewicz, Makova & Medvedev, Nature Communications, 2018) — which clusters and corrects long reads, then runs a threshold-free per-variant test of whether each candidate transcript is a real variant or a sequencing-error artifact in a multicopy gene family. We apply the same test to decide which copy a read came from. Our additions: the copy-vs-allele distinction, assign-or-abstain (a read goes to one copy or none), and no 1/k.

Fine print · two questions people ask

Is the read assigned to the copy with the most matching PSVs?
No — it is two separate steps, and neither is a count. Which copy: the read goes to the copy of maximum likelihood — an argmax over a per-column log-likelihood ratio, each column weighted by that base's own quality ε — so a single high-quality PSV can outweigh several weak agreements; it is not a vote tally. Whether to commit: the minimum-probability certificate shown above, p < α/(K−1), plus an identifiability gate — at least one column or junction must actually separate the winner from a rival. No distinguishing column → tied; distinguishing but not significant → ambiguous. The number of PSVs enters only through p (more/sharper ones ⇒ smaller p), never as a hard threshold like "≥ 2 PSVs" — that is the deliberate break from vote-count / AS ≥ 10 rules.
What is the de tag, and why it and not the alignment score?
de is minimap2's gap-compressed divergence — mismatches per aligned base, a rate in [0,1]. It decides the conflict graph that scopes the family: two placements of one read conflict iff neither can significantly out-align the other, using the same εδ ≥ α real-vs-error test as this page (δ = the excess mismatch count) — and that graph is what χ_H counts. We use de, not the raw alignment score AS, because AS is a total that grows with aligned length: a partial second alignment scores far lower even at identical per-base quality (on GGO, runner-up/best AS ratio 0.71 while the length ratio is 0.90). So AS is only reported (for the Eichler AS ≥ 10 comparison); de decides.
