### §3.2 Mappings (declared by the user 2026-09-16 22:59, before any new number; verbatim)

- M1 (the frozen rule): the node with the most exon-bp overlap with the copy's RefSeq exons; ties → larger gene-span overlap.
- M2 (strand-aware, spliced first): among nodes overlapping the copy's exons, take the most exon-bp node that is on the copy's strand AND has >= 2 exons; if none, the most exon-bp node on the copy's strand; if none, M1.
- M3 (majority group, all nodes including single-exon ones): the copy's predicted group = the group whose nodes TOGETHER cover the most of the copy's exon bp (sum over every overlapping node, single-exon nodes included; union of intervals within a group, not double-counted); ties → the group containing the M1 node, then lower group id. A copy whose overlapping nodes are all outside any family is a singleton; no overlapping node → MISSING.
- For catalogs that list only family members (no dump of all nodes), a truth copy with no overlapping listed copy is "PRESENT-UNGROUPED OR MISSING (undistinguishable)"; if possible, distinguish with the catalog's own loci/nodes table or by counting primary MAPQ>=1 reads on the copy's exons in the catalog's BAM (report the read count), but score it as a singleton either way and label it.
