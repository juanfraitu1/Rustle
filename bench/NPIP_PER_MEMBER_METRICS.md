That tie goes to the earlier truth group in sort order. (A first run without the unmatched columns ignored the rank tie-break whenever #predicted ≤ #truth groups. It was corrected before this file was written. The fix changed only SUBFAMILY-2 matches and P strict: DN0 0.185 → 0.175, DN1r+B 0.250 → 0.231.) MISSING singleton groups take part in the matching, as the definition says; the per-level lines report how many matched pairs are such singletons.
6. Pairwise over pairs of the 27 truth copies (= `guided_pipeline.pairwise`): sens = TP/(TP+FN), prec NPIP-only = TP/(TP+FP). Prec strict additionally counts as FP every co-grouped pair that involves a non-truth node of a group holding ≥ 1 truth copy (as `soto_holdout.py`'s P_strict).
