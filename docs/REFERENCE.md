## Glossary — what each term denotes
"Locus" has two senses: **gene locus** (isoforms collapsed by shared splice junctions) vs **physical span** (`(chrom, start, end)`, used for the >= 2 distinct-loci certificate, reciprocal overlap >= 50% = same). **Isoform** = one intron chain. **Copy / member** = a gene locus in a multi-copy family. **Family** = a connected block of the copy graph (read-supported genomic nodes, contiguous high-coverage homology edges; `seeded_family_definition.md` §1★, shipped §0★ 2026-09-25; code `family.rs`, `mcl_families.rs`); SD / duplicon / expansion are the layers below (`TERMINOLOGY_FAMILY_SD_DUPLICON_EXPANSION_2026-10-07.md`); the γ-quasi-clique code was retired (opt-in `gw_family_catalog`). Known limitation: isoforms with disjoint intron sets split into false paralogs; span-aware collapse mitigated it. Formal notes: DNA/protein notes use the physical-span sense, the RNA note the gene-locus sense. (full: archive/2026-11/REFERENCE.md:10)
